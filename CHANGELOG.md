# Changelog

All notable changes to Northstar Payments API are recorded here.

## [0.2.0] - 2026-09-20

- Added HTTP integration coverage for health and payment lookup flows.
- Added repeatable CI helper scripts for unit, integration, and build validation.
- Added container packaging and local Compose support.
- Expanded contributor and local development documentation.

## [0.1.0] - 2026-09-08

- Added the in-memory payment lookup service.
- Added request IDs and the health endpoint.
- Added TypeScript build configuration and unit coverage.
