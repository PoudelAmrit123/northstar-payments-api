# Contributing

Thanks for helping improve Northstar Payments API. Small, focused changes are easiest to review and release.

1. Fork this repository on GitHub.
2. Create a branch for your change.
3. Implement the change and add or update tests.
4. Run `npm ci`, `npm test`, `npm run lint`, and `npm run build` locally.
5. Push your branch and open a pull request against `main`.

Please describe the user-facing behavior, test coverage, and any configuration changes in the pull request body. Avoid committing local environment files, credentials, generated output, or dependency directories.
